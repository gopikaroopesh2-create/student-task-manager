Student Task Manager

A simple student task management application developed using HTML, CSS, and JavaScript.

Features

- Add new study tasks
- Mark tasks as completed using a strikethrough effect
- Delete tasks
- Display the total number of tasks
- Save tasks using localStorage
- Retain tasks after refreshing the page

Technologies Used

- HTML
- CSS
- JavaScript
- Browser localStorage

How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Open "index.html" in a web browser.
4. Start adding and managing your study tasks.

Purpose

This project was created to practise front-end web development, JavaScript functions, DOM manipulation, event handling, and localStorage for saving data in the browser.
